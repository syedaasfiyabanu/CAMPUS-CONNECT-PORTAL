About Campus Connect

Campus Connect is a student-first learning platform designed to bridge the gap between academic theory and industry practice. Built by students, for students, it offers structured learning paths across computer science, engineering, and design disciplines.

This page is built as part of Experiment 2 of the Web Technologies Lab. It demonstrates semantic HTML5 elements, an external CSS3 stylesheet, Flexbox-based card layout, CSS Grid for two-column content, hover effects, and responsive media queries.
